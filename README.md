PasoFirme - Sistema de Gestión de Calzados

Proyecto académico desarrollado para la materia de Tecnología Web I de la Universidad Privada Domingo Savio (UPDS - Cochabamba).

📝 Descripción del Proyecto

"PasoFirme" es una aplicación web diseñada para automatizar el control de inventarios por tallas y modelos, el registro de ventas y la gestión de caja para una tienda de calzados. Su objetivo principal es optimizar los tiempos de atención al cliente y garantizar precisión en la administración comercial y financiera.

🛠️ Stack Tecnológico

Backend: PHP (Procedural)

Base de Datos: MySQL / MariaDB

Frontend: HTML5, CSS3, Tailwind CSS (Vía CDN)

Entorno Local: Laragon

⚙️ Instrucciones de Instalación (Para el equipo)

Clonar este repositorio dentro de la carpeta www de Laragon (C:\laragon\www):

git clone https://github.com/NilsOliver06/paso_firme.git


Iniciar los servicios de Apache y MySQL en Laragon.

Abrir HeidiSQL o phpMyAdmin y crear una base de datos llamada paso_firme_db.

Importar el script SQL (proporcionado en la documentación) para crear las tablas correspondientes.

Acceder en el navegador a: http://localhost/paso_firme/login.php
